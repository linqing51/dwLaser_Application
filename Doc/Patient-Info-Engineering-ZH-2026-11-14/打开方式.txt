无需联网、安装开发环境或字体。中文优先使用电脑自带微软雅黑，其次苹方。
高亮测试：首次进入参数界面患者图标亮起；调节任一参数或点击患者图标立即熄灭。重启模拟设备后重新提示。
默认按1024×600原尺寸显示，演示控件位于下方。窗口较小时取消“原始尺寸 / Actual Size”可缩放查看。
分页测试：设备 A / Device A → 患者图标 → Ankita · AR 0002 → 治疗记录（10）/ Treatment Records (10) → 下一页 / Next。
满记录测试：选择 Ankita · AR 0002 → 模拟治疗 → 待机 → 保存记录 → 管理记录；直接打开该患者历史。删除旧记录后，点击返回核对继续保存。
删除测试：选择患者后重新打开患者列表，直接点击同行“删除患者 / Delete Patient”；确认后删除患者及历史，并清除当前选择。
USB B 演示：选择 USB B → 患者列表 → USB 导入／导出 → 从 USB 导入 → 替换并导入；设备变为2位患者、合计2条记录。导出成功会清空设备，失败时保留原数据。
跨设备测试：Device A → USB Transfer 导出到 USB A → Device B → USB Transfer 导入并确认替换。
本原型的设备存储与 USB 均为内存模拟；Restart Demo Device 保留已保存数据，刷新网页重置整个演示。
使用说明.md：演示操作；实现说明.md：工程交接；字号与颜色规格.md：UI规格；source：完整源码。
