# 方案 3：设备保存、USB 备份与按钮分页

版本：2026-11-14。双击 index.html 打开，保留 assets 文件夹。中英文版共用同一套交互；中文版工程包的 index.html 为中文，english.html 为英文。中文采用电脑自带字库，英文 Myriad Pro 已内嵌；只输入虚构患者资料。下文操作名采用英文，中文版为对应中文按钮。

## 患者图标高亮

开机首次进入参数调节界面时高亮。开始调节任一参数（包括触碰滑块但数值未变化）或点击患者图标进入列表后立即熄灭。直接点击 Ready 也会熄灭；本次开机内返回参数界面不重复亮起。点击 Restart Demo Device 可重新演示高亮。

## 本次变化

患者资料与治疗记录改为保存在设备中；USB 只用于导出备份或导入整套档案。每台设备上限 380 人，每人 10 条记录，姓名最多 18 个字符（空格计入）。

容量满时阻止新增，可导出全部档案并清空设备，或手动删除旧资料；不自动覆盖最旧记录。
导入采用整库替换，明确确认后才执行，导入前提示把当前设备资料备份到另一块 USB。超限或格式不兼容则整次拒绝，不部分导入、不截断姓名。

## 直接查看两页治疗记录

1. 默认 Device A，点击右上角高亮患者图标。
2. 第一页找到 Ankita · AR 0002，点击 Treatment Records (10)。
3. 弹窗显示最新 5 条完整摘要及对应删除按钮。
4. 点击 Next 查看另外 5 条；Previous 返回；Close 关闭弹窗。
5. 历史弹窗中的 Edit Patient 修改基本资料，Delete Treatment Record 只删除对应一条记录。患者列表直接提供并排的 Select Patient 与 Delete Patient；删除患者及其全部历史前会确认范围，无需进入历史弹窗。
6. 患者列表每页 5 人，Previous / Next、页码与 Close 位于同一底栏；10 位患者只需两页。搜索后回到第一页，无滑动列表和折叠历史。

## 登记与保存治疗

1. 可术前选择已有患者或 + New Patient；姓名必填，ID 自动生成，年龄/性别可选。
2. Save and Select Patient 保存患者到当前设备并选中，不创建空治疗记录。
3. 也可不选患者直接 Ready，按住模拟脚踏输出，松开暂停。
4. 点击 Standby 结束本次治疗：先回到参数界面，再自动打开核对卡。有输出才生成记录。
5. 核对患者与摘要，必要时 Change Patient；Save Record 保存到设备，Discard Record 需再次确认。
6. 保存成功或放弃后清除本次患者选择；不可跳过核对卡。
7. 即使选择画面外 No USB，登记、历史查看和治疗保存仍可使用。

## 容量满时的处理

- 列表顶部显示已保存患者数 / 380，历史弹窗显示该患者记录数 / 10。
- 第 381 位患者、第 11 条记录都会被阻止保存，不自动删除旧资料。
- 当前患者已有10条记录时，点击 Manage Records 直接打开该患者的治疗历史，每页5条。无需再次从患者列表寻找该患者。
- 治疗历史弹窗不再提供 USB 入口。USB Transfer 只在患者列表页；如需从核对卡前往该页，先返回核对，再点击 Change Patient。确认删除旧记录后，点击 Back to Review 直接回本次核对，再点击 Save Record。本次患者身份及待保存治疗保持不变。
- 新建患者因设备已满380人而受阻时，Manage Records 仍打开患者列表，供备份和清理旧患者；未保存的新患者资料及本次治疗保留。
- 已选患者也可以删除。确认后，患者资料及全部已保存历史被删除，当前患者选择被清除。取消确认或写入失败则保留原资料和选择。
- 若删除患者时，本次治疗尚未保存，则保留该治疗摘要并自动返回核对卡，重新选择或登记患者后才能保存。删除其他患者不会清除本次患者选择。
- USB 导出不包含尚未保存的本次治疗。核对未处理期间不能导入或切换设备。

## USB 导出与跨设备导入

1. 在患者列表点击 USB Transfer，选择 Export to USB。
2. 确认导出范围；如 USB 已有备份，确认后替换其旧备份。导出成功后清空设备中的患者及治疗记录；取消或失败时不清空。
3. 通过画面外 Simulated device 切换 Device B 或 C。此时显示该设备自己的档案，不会自动加载 USB 患者。
4. 进入患者列表 → USB Transfer → Import from USB。
5. 弹窗列出本机及备份的数量，并提示先备份本机数据。确认 Replace and Import 后才整库替换；Cancel 不修改任何资料。
6. 原患者 ID、内部身份和治疗来源设备保持不变。之后新治疗记录属于当前设备。
7. USB A、USB B 是不同备份；插拔与更换 USB 不改变当前设备患者选择。

## 演示控件

这些控件位于 1024 × 600 设备画布之外，不属于正式设备操作：

- Device A/B/C：三台独立的模拟设备。
- USB A/B / No USB：两个模拟备份介质或拔出。
- Simulate device storage failure：设备保存、修改、删除或导入失败；原数据保留，取消勾选后重试。
- Simulate USB write failure：导出失败；旧备份保留，取消勾选后重试。
- Simulate newer USB format：在已有备份上模拟不兼容版本；导入被阻止，本机数据仍可使用。
- Restart Demo Device：保留虚拟介质中已保存的数据，清除运行状态与患者选择。
- Actual Size：默认原始 1024 × 600 像素；取消可缩放适应电脑窗口。

HTML 中设备存储和 USB 都是内存模拟，不实际读写电脑 USB。刷新或关闭网页会重置全部演示数据，这与 Restart Demo Device 不同。正式设备应将已保存资料存入设备非易失存储。
原设备参数交互和先退出可发射状态再核对的顺序保留；450 ms 视觉过渡不代表真实硬件安全确认。

## USB B 覆盖导入演示

1. 在画布下方选择“模拟 USB → USB B”。
2. 打开患者列表，在“+ 新增患者”旁点击“USB 导入／导出”。
3. USB 备份显示2位患者、2条治疗记录。点击“从 USB 导入”。
4. 核对原设备数量与备份数量，点击“替换并导入”。
5. 返回患者列表，只剩 Emma Wilson 和 Daniel Chen，各有一条记录，原设备患者已被替换。

导出改为“导出并清空设备”：成功后设备已保存档案清空，USB 保存完整备份；失败时原数据保留。若还有未保存治疗，其摘要保留，需重新登记或选择患者。
