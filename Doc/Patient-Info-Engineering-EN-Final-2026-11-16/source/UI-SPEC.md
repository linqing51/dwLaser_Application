# 患者信息 UI 规格 · 10.1 寸 / 1024 × 600

版本：2026-11-14。数值为设备画布原始 CSS px。英文版沿用原设备 Myriad Pro Regular，字重 400；Device Myriad 是内嵌字体别名。中文版优先使用微软雅黑，其次苹方、Noto Sans CJK SC，使用电脑现有字库，无需联网。正式设备须配置相应中文屏幕字库，系统字库差异需实机验收。
两版患者页面的字号、行高和颜色保持一致，见下表。正文、数字及按钮额外字间距 0 px；英文全大写顶部标签为 1 px，中文顶部标签为 0 px。字体色不额外降低透明度，禁用按钮例外。

## 固定页面与弹窗

- 设备画布 1024 × 600。患者列表内边距上下12 px、左右24 px，标题区52 px、搜索框44 px；每页5个72 px高的患者行，行间距6 px。姓名、资料和按钮字号保持不变。
- 翻页、页码、Close 与 Clear Patient Selection 合并到44 px高的同一底栏。移除底部重复的患者总数和存储位置说明，患者总数仍保留在顶部。容量满或保存失败的说明使用独立22 px高提示行；五位患者仍完整显示。无滑动列表。
- 历史弹窗 976 × 576，居中 x=24、y=12。内边距上下12、左右20；1 px 边线。
- 历史标题区 52 px；记录区固定 280 px，由 5 行 × 56 px 构成；分页行44 px，底部管理按钮行44 px。区域间距8 px。
- 从核对卡 Manage Records 进入时，直接显示当前患者的历史弹窗；底栏仅保留 Back to Review，直接返回核对卡。USB Transfer 入口只在带 + New Patient 的患者列表页。
- 每条历史记录用两行文字完整呈现摘要；删除按钮固定为18 px、至少44 px高。10条记录显示为两页，最新记录在第一页。
- 无记录时显示 No treatment records saved.，Previous / Next 均禁用。删除后不足两页时回到有效页。
- 取消旧的折叠箭头和内联展开区域。整个弹窗不滚动，不使用滑动翻页。
- 患者列表每行右侧依次为 Treatment Records (n)、Select Patient、Delete Patient；后两个按钮水平并排，按钮至少44 px高，Delete Patient 为18 px淡红色描边样式。已选患者的删除按钮也可使用。
- Delete Patient 从治疗历史弹窗移至患者列表。确认弹窗显示姓名、ID及删除记录数量；已选患者另有清除选择的提示，若有未保存治疗则说明保留摘要并重新选择患者。
- 删除与导入导出确认都显示在设备画布内；默认弹窗宽680 px，内边距24 px，不点击背景关闭。
- 核对卡 x=52、y=24、宽920、高552。内边距16 px，标题区56 px；患者字段、摘要和底部按钮不依赖滚动。核对中的患者管理使用整个设备画布，历史弹窗仍保持上述固定尺寸。
- 同名选择页采用分页，正常每页3人、核对卡内每页2人。
- 输入框及普通按钮至少44 px高，核对主按钮至少48 px高。姓名输入最多18个字符（空格计入）；不缩小字体以塞入超长姓名。

## 背景及工程映射

- 黑灰径向渐变：中心 #303032 → #1B1B1D → #09090A → 边缘 #030304。
- 患者行为薄边线灰色横向渐变，紫色仅用于操作提示与主按钮。
- 删除按钮文字 #F0B4A9；最终删除 / 替换确认按钮白字 #FFFFFF，底色 #843E36。
- 串口屏可复用固定背景、文字区域和触摸区域，翻页仅替换文字及绑定记录，不需要每页制作新背景或滑动帧。
- 英文版保留原设备主界面和 Ready 等特殊字型；新增患者身份显示 Myriad Pro 16 px。中文版在原背景上覆盖中文标签，保持同一控件位置与参数操作；患者身份使用中文系统字库16 px。

已按内嵌字体测量18字符宽姓名及记录两行文字的占用宽度，并检查固定区域尺寸。自动浏览器视觉验收受既有访问策略限制；最终还需在1024 × 600实机检查渲染、触摸、键盘及不同光照下的可读性。
