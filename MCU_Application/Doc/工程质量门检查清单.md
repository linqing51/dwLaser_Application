当前活跃工程示例分散加载 `targetBoard_G5_TRI_A1_20260915/MCU_Application.sct`，其固定区域配置如下（**G5/STM32F405 示例，其他板以各自 `.sct` 与 BoardConfig 为准**）；各区域当前占用与空闲以最新 `.map` 的 Execution Region 行实测为准：

## 3. FRAM 数据完整性门

- [ ] 病历区块为浮动区域，统一引用宏：`CONFIG_EPROM_TREATMENT_START/END/SIZE`（BoardConfig.h，自动占满剩余空间）；行尺寸 `CONFIG_EPROM_PATIENT_RECORD_SIZE`、`CONFIG_EPROM_TREATMENT_RECORD_SIZE`（sizeof 派生）。
- [ ] 物理容量以 `TREATMENT_PHYSICAL_PATIENT_CAP`（treatment.h）为准；写入受 `InRegion`/`FreeBytesPR` 软件防护，不依赖硬件块保护。
- [ ] FRAM 状态寄存器 BP1/BP0 保持关闭（写 `0x00`），不得开启硬件块保护。
- [ ] 断电原子提交依赖行 magic 状态机：BLANK `0xFF` / PENDING `0x33` / COMMIT `0x5A` / TOMB `0xA5`；新增写入路径必须经 PENDING→COMMIT，删除走 TOMB 后致密。
- [ ] 固件 CRC 变化（首次烧录/升级/CRC 失败恢复）时 `treatmentEpromClear()` 清空病历是预期设计，不做旧格式迁移、不新增兼容逻辑。
- [ ] 患者编号最小空缺优先回收复用、无空缺才取最大 ID+1；无实际激光输出不建治疗记录。
