## 工具链已知坑（重要，避免重复踩坑）

- 若工程 ARM Compiler 选项为 **"Use default compiler version 5"（使用默认编译器版本5）**，在命令行 UV4 下可能因全局默认解析异常，把 AC5 工程错误解析到 `ARMCLANG` 目录、却仍调用 AC5 的可执行文件名，拼出不存在的 `C:\Keil_v5\ARM\ARMCLANG\Bin\ArmCC`，报 `CreateProcess failed`。
- 正确复位方式：Keil GUI → Options for Target (Alt+F7) → Target → ARM Compiler，**明确选择具体版本 `V5.06 update 7 (build 960)`**（不要用"默认"）。保存后工程会新增一行 `<pArmCC>5060960::V5.06 update 7 (build 960)::.\ARMCC</pArmCC>`，命令行即可正确解析到 `ARMCC\Bin`。
- 强制完整重编用 `-r`；`-b` 可能只做增量。
